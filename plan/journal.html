日志线：一天一个 mdx 文件

2026-10-12 · 与论文线并行，互不依赖 · 完全替代 bn-journal · 里程碑记在本仓 trajectory/ 根卡

日志是时间序列，就用时间序列的形状存：一天一个 mdx 文件，文件名即日期。月历、统计、全库待办全部从文件算出来，不需要任何查询引擎。保留 mdx 输入的灵活性——文件本身是全功能的，渲染渐进跟上。

✓ 这一阶段做

  • 文件格式定义与数据落位（J1）
  • 读：月历、每天统计、全库待办（含过期）、连续天数（J2）
  • 写：记一笔、排待办、改期、勾掉；快速记录的落点（J2）
  • 界面照搬：旧 bn-journal 的月历、正文、待办、快速记录设计直接沿用（J3）
  • 行尾标签：行尾 #名字，两条回看命令（journal.tags 聚合计数 / journal.tagged 列一个标签的全部行）（J2）
  • 旧 journal 块迁移成按天文件（J4）

✗ 这一阶段不做

  • 撤销历史（建议接受没有——背景页决策二）
  • 标签体系与评论：bn-tags 的层级标签块、bn-comment 不为日志复活——行尾 #名字 是文本，不是体系
  • 块查询引擎、字段声明体系、提交与冲突协议——全都没有
  • mdx 组件系统与编译渲染（第一版按普通 markdown 渲染，见下）

J1格式与数据

journal/
├── 2026-10-10.mdx
├── 2026-10-11.mdx
└── 2026-10-12.mdx
holidays.json          法定假日数据，照搬旧插件每年下载的文件
  • 文件名即日期、即唯一键：YYYY-MM-DD.mdx。认一天只看文件名，不看内容。
  • frontmatter 放元数据：第一版允许为空；需要时再加字段（比如标记某天只在别处引用过）。不为未来预设。
  • 正文是 mdx：对人就是 markdown 超集，想写组件、写表格、嵌结构化内容都行；待办就是普通的 - [ ] / - [x] 行，不发明新语法。
  • 排未来的事：未来的日期也直接建文件，文件里一行待办；改期 = 把那一行挪到另一天的文件里。文件可以只有一行。
  • 跨天引用：相对链接到另一天的文件（[10月8日](./2026-10-08.mdx)），替代旧的块引用。
  • 渲染策略：格式全功能、渲染渐进。mdx 的成本全在渲染侧（编译、组件注册），存储侧为零。第一版渲染按普通 markdown 处理（组件原样显示源码即可），等真用到组件再上编译——文件不用改，只升级渲染器。

J2读与写

能力做法
月历扫文件名 + 假日数据；窗口含两端最多 400 天，每天的条目数、待办数直接读文件
每天统计写了多少条、几个待办、完成几个；有内容的日子列表
全库待办扫全部文件的 checklist 行；早于今天还没勾的就是过期，排前面的按日期倒序
连续天数有内容的日子连着算；current 今天没写从昨天起算——口径照搬旧插件
记一笔 / 排待办对人是编辑文件；对 agent 直接读写文件（没有也可以加一条薄命令，实现时定，别造成第二个提交协议）
勾掉待办- [ ] 改 - [x]，纯文本编辑
快速记录状态栏入口照旧，写进今天的文件末尾
行尾标签一行末尾写 #名字（中文随便用，可挂几个）；名字里写 / 表示层级（#仿真/MMC 算打了「仿真」）。journal.tags 按路径段组树、journal.tagged 列一个标签的全部行按日期倒序（默认连下级）。没有名字表与改名管理；标签窗格看全部标签

J3界面：照搬旧设计

旧 bn-journal 的界面设计直接照搬，不重新设计交互。月历窗格、正文窗格、窗格下方全库待办、状态栏快速记录——布局与交互在新插件里原样重建，只是数据源从块库换成按天 mdx 文件：

  • 月历：点一天打开那天的文件；还没有那天的文件时显示一页空白，写下第一行才建文件——「只点不写不留下空的日子」的行为照搬。
  • 正文窗格：从渲染块树换成渲染 mdx；第一版按普通 markdown 渲染（见 J1 的渲染策略），窗格本身照旧。
  • 全库待办、状态栏快速记录：行为与位置照搬，读写落到文件。
  • 顺序：J1、J2 先做完（数据与命令可用），J3 独立做——它不阻塞任何数据工作。

J4迁移

  1. 旧 journal 块按天导出：每天底下的普通块按顺序变成 mdx 行，待办的勾选状态保留；空的未来日期不导出。
  2. 对账：天数一致、待办数一致、勾选状态一致；抽查三天人工比对。
  3. 全绿后：旧 bn-journal 随整体退役一起卸载（与背景页决策一联动）。

验收标准

  • J1–J2 过：迁移后的数据算出的月历、每天统计、全库待办、连续天数与旧插件口径一致，行尾标签的聚合计数与文件一致；记一笔→月历可见→勾掉全链路走通；未来日期排待办、改期走通。
  • J3 过：照搬的月历、正文、全库待办、快速记录在深浅主题与窄窗口下通过一轮使用验收。
  • J4 过：对账清单全绿。
